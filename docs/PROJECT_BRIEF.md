## B. GOLDEN RULES (apply in every phase)

1. **NEVER invent facts:** no client names, real-sounding project names, testimonials, reviews, ratings, statistics, awards, certifications, team members, years in business, project counts, revenue or results. Use clear placeholders like "Project details coming soon" when information is missing.
2. **Keep copy SHORT.** No paragraph longer than 2-3 lines on desktop.
3. **Mobile is designed on purpose,** not shrunk from desktop.
4. **No heavy libraries:** no Tailwind, Framer Motion, GSAP, UI kits or jQuery. Use CSS + IntersectionObserver for animation.
5. **Every color, radius, font size and spacing value comes from CSS variables.**
6. **No social media links anywhere.**
7. **Images will be generated in Phase 2** in one consistent art direction. Never use random stock photos, faces, humanoid robots, or text/logos inside images.
8. **Accessibility, responsiveness** (320px to 1920px) and performance matter in every phase.
